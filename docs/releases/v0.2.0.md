# Agent Fault Lab v0.2.0 — Phase 2 reliability

Stable release dated 2026-09-07. The maintainer confirmed the remaining Phase 2
reviews complete and authorized promotion from v0.2.0rc1. This release updates
version metadata and documentation; runtime behavior and dependency versions are
unchanged from the candidate.

## Included

- **M06:** strict tool-result contracts and malformed-data experiments.
- **M07:** before-write/lost-reply failures, bounded retries and atomic operation-ID
  replay, with independent duplicate-effect evaluation.
- **M08:** process supervision, transient recovery, deadlines, termination and
  confirmed worker cleanup.
- **M09:** durable conversation checkpoints, persistent budgets and protected
  crash/restart recovery.
- **M10:** read-only diagnostic timelines with evidence references and explicit gaps.

The original dropped-write comparison and saved-report readers remain supported.
Start with the [offline quickstart](../../README.md#quickstart), then use the
[milestone walkthroughs](../roadmap.md) to explore each experiment.

## Evidence and boundaries

The stable version passed 440 offline tests, isolated installed-wheel verification
and [Ubuntu/macOS CI](https://github.com/dharmendrathinks/agent-fault-lab/actions/runs/34133725234)
on original release commit `6a6a141`. Its corrected author/committer version,
`ce748c0`, has an identical file tree. Downloaded packages match their SHA-256 checksums.
Publication evidence is recorded in [PROGRESS.md](../../PROGRESS.md).
Promotion adds no new inference or benchmark
claims; the [candidate findings](v0.2.0rc1.md#evidence-and-interpretation) remain intact.
Live runs include duplicate effects under unprotected retry, wrong-ID completion
claims and a false non-completion after a committed write.

Operation-ID replay protects one retained key and matching payload in this SQLite
workflow; it is not an end-to-end exactly-once guarantee. Cancellation cannot undo
a committed write. Diagnosis uses saved evidence without fresh evaluation.
See [known limitations](../known-limitations.md).

Resume checks the package/source fingerprint, including the version. Resume
v0.2.0rc1 runs with their original candidate checkout and environment; v0.2.0 can
still read their saved reports and diagnostics. The candidate tag and packages
remain available. Python 3.12 and macOS/Linux process control are required.

## Packages

The stable GitHub release provides `agent_fault_lab-0.2.0-py3-none-any.whl`,
`agent_fault_lab-0.2.0.tar.gz` and `SHA256SUMS`. Download all three into one directory
and run `shasum -a 256 -c SHA256SUMS` to verify the package bytes.

For locked development setup, check out `v0.2.0` and follow the README.
No PyPI package, model weights or private run data are published with this release.
