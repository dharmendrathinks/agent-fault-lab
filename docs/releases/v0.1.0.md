# Agent Fault Lab v0.1.0 — release notes

Status: release candidate materials; no tag or published release yet.

## Included

- File-backed synthetic task workflow with strict input contracts.
- Bounded local Ollama tool-calling loop and deterministic scripted client.
- Independent read-only SQLite evaluator and strict terminal-claim validation.
- Controlled dropped-write fault and baseline/read-back four-cell comparison.
- Saved JSONL traces, machine-readable evidence, Markdown reports, and accounting.
- Deterministic `aflab report` regeneration and read-only `--check` mode.
- Captured, explicitly scripted public report excerpt with reproducibility tests.
- Socket-blocked offline test suite, isolated wheel checks, Ubuntu/macOS CI, and an
  explicitly gated local-model smoke test.

## Evidence

The first live batch is retained even though its model setup made the intended
comparison unscorable. A later bounded smoke removed the output-format limitation
and exposed ID-copying failures. See [the experiment summary](../experiment.md).

## Boundaries

This release is a learning lab, not a production framework, model leaderboard,
security certification, or claim that read-back is generally effective. Read the
[known limitations](../known-limitations.md) before interpreting results.
