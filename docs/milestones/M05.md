# M05 — Reproducible v0.1 packaging

M05 turns the first experiment into something another engineer can install,
inspect, verify, and critique. It adds no new reliability treatment.

## What report regeneration proves

`aflab report RUN_DIRECTORY` validates saved machine-readable evidence and derives
the Markdown again. If someone edits `report.md` to make a result look better,
`aflab report RUN_DIRECTORY --check` returns 1. Regeneration replaces only the
report after all input validation succeeds.

It does **not** prove the JSON is authentic or re-evaluate SQLite. That separation
is deliberate: reproduction of presentation and reproduction of an experiment are
different claims.

## Reproduce without a model

```sh
uv sync --locked --all-groups
make check
uv run --offline --no-sync aflab compare --offline --trials 1
uv run --offline --no-sync aflab report runs/YOUR-COMPARISON --check
```

The comparison is scripted test machinery. It verifies storage, fault, evaluation,
accounting, artifact, and rendering paths without pretending to measure a model.

## Live boundary

Neither CI nor `make check` can contact Ollama. A human must separately invoke
`AFLAB_RUN_LIVE_TESTS=1 make live-test`; no model is downloaded automatically.
The smoke validates evidence production, not task success or model reliability.
