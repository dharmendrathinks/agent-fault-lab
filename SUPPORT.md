# Support

Start with the [quickstart](README.md#quickstart),
[troubleshooting](docs/troubleshooting.md) and [limitations](docs/known-limitations.md).

Use [GitHub Issues](https://github.com/dharmendrathinks/agent-fault-lab/issues)
for bugs, experiment proposals and concise usage questions. Search first. Include
a synthetic reproduction, exact command, version and expected versus actual result.
Label scripted and live results separately.

Use [SECURITY.md](SECURITY.md) for vulnerabilities and
[CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) for conduct concerns.

This is independently maintained experimental software. No paid support contract,
guaranteed response time or production-readiness warranty is offered.
